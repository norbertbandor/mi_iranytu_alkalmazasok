# mi_iranytu_alkalmazasok
 Az MI Iránytű csapata által készített és az oldalon bemutatott kis alkalmazások gyűjteménye: az alkalmazásokat bárki szabadon letölthet, felhasználhat és továbbfejleszthet.     A collection of small applications created and showcased by the MI Iránytű team. These tools are freely available for anyone to use and build upon.
